
# Student Information System - DBMS Project

## Overview
This project is a Student Information System developed using MySQL.  
The project demonstrates fundamental DBMS concepts such as table creation, relationships, joins, aggregate functions, subqueries, and views.

---

## Features
- Database creation using SQL
- Table creation with Primary Keys and Foreign Keys
- Data insertion into tables
- SQL JOIN operations
- Aggregate functions like AVG and MAX
- Subqueries
- Views creation
- Student and course management

---

## Database Tables
The project contains the following tables:

1. Departments
2. Students
3. Courses
4. Enrollments
5. Marks

---

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT Queries
- INNER JOIN
- GROUP BY
- Aggregate Functions
- Subqueries
- Views

---

## Sample Operations Performed
- Retrieve student names with courses and marks
- Calculate average marks per course
- Find highest marks scored
- Display department-wise student information
- Create and use SQL Views

---

## Technologies Used
- MySQL
- SQL

## Project Purpose
This project was created as part of a DBMS academic mini project to demonstrate practical implementation of relational database concepts using MySQL.
